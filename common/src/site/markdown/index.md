# FHIR Dosage Support - Common  
  
Shared utilities and foundational components for handling FHIR Dosage transformation and processing.  
  
This module is not meant to be used directly by consumers of the library. It provides:  
  
- Shared internal utilities reused by the [R4](../r4/) and [R5](../r5/) modules  
- A `test-jar` classifier artifact with common test templates, used internally to keep R4/R5 test suites consistent
